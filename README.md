# QuotaBar downloads

Desktop installers and website release bundles for [QuotaBar](https://quotabar.mjband.com/).

macOS 14+ (Apple Silicon / Intel), Windows 10/11 x64, Linux x86_64.
The application reads quotas from locally authenticated AI clients. The website provides
installation instructions and SHA-256 checksums. macOS builds use ad-hoc signing;
Windows installers are unsigned.
